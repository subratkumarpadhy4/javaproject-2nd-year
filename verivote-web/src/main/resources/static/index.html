About VeriVote-J Platform

VeriVote-J is a fully connected educational voting platform backed by a live Spring Boot application and PostgreSQL database. It features blind-signature RSA token issuance, Zero-Knowledge proof cryptographic receipts, Merkle-tree audit ledger, and real-time polling — allowing students and civic groups to understand transparent digital elections.

Platform Features

  • Live PostgreSQL database for real ballot storage
  • RSA Blind-Signature anonymous token issuance
  • Merkle ledger with Ed25519-signed checkpoints
  • Web Audio feedback synthesizer
  • ZK Cryptographic receipt generation

Backend Endpoints

  • GET /api/web/election
  • POST /api/web/demo-auth
  • POST /api/web/request-token
  • POST /api/web/cast-vote
  • GET /api/web/verify/{hash}
  • GET /bb/receipts & /bb/checkpoints
